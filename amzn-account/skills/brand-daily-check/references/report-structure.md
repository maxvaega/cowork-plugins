# Report Structure Reference — Brand Daily Check

Full specification for the final client report generated by the `report-compiler` agent.
The report is written in Italian and converted to Word (.docx) for delivery to the seller.

---

## Report Sections

### 1. Header

```
# Amazon Brand Report — [Brand Name]

**Data controllo**: [GG/MM/AAAA]
**Marketplace**: [comma-separated, e.g. IT, DE, FR]
**ASINs controllati**: [N]
**Preparato da**: Amazon Account Management
```

Purpose: Clear identification of what was checked, when, and by whom.

---

### 2. Stato Generale (Executive Summary)

The most important section — many sellers read only this.

Format:
```
## Stato Generale del Brand

### [🟢 Tutto OK / 🟡 Attenzione richiesta / 🔴 Intervento urgente necessario]

[2-3 sentences max. Direct, factual, actionable.]
```

**Status determination:**
- 🔴 CRITICO → "🔴 Intervento urgente necessario"
- 🟡 ATTENZIONE → "🟡 Attenzione richiesta"
- 🟢 OK → "🟢 Tutto OK"

**Writing the summary paragraph:**
- State the overall health in one sentence
- Name the most critical issue (if any), with which ASIN
- End with a forward-looking note ("Si consiglia di..." or "Nessuna azione urgente richiesta.")

Example for 🔴:
> "Il brand necessita di intervento urgente su amazon.it. La Buy Box dell'ASIN B0XXXX è stata sottratta dal venditore terzo 'FastShop EU' che vende a €3 in meno rispetto al prezzo ufficiale. Gli altri prodotti sono in ordine. Si consiglia di contattare Amazon Seller Support oggi."

Example for 🟢:
> "Il brand è in ottima salute su tutti i marketplace controllati. Tutti i prodotti sono disponibili, la Buy Box è correttamente detenuta dal brand e il rating medio è 4.4/5. Nessuna azione urgente richiesta."

---

### 3. Riepilogo Prodotti (Product Overview Table)

```
## Riepilogo Prodotti

| ASIN | Prodotto | Prezzo | Buy Box | Rating | Stato |
|------|----------|--------|---------|--------|-------|
| B0XXXX | [name ≤35 chars] | €XX,XX | ✅ Brand | 4.3★ | 🟢 |
| B0YYYY | [name ≤35 chars] | €XX,XX | ❌ 3rd party | 3.8★ | 🔴 |
```

**Column rules:**
- ASIN: 10-char code, clickable in Word (hyperlink to URL if possible)
- Prodotto: truncate at 35 chars with "…" if longer
- Prezzo: Italian format (€XX,XX) — the Buy Box price
- Buy Box: ✅ + holder name for OK; ❌ + seller name for lost
- Rating: X.X★ format
- Stato: emoji only (🟢/🟡/🔴)

---

### 4. Problemi Rilevati (Issues Found)

Only include if there are issues. Three priority levels:

```
## Problemi Rilevati

### 🔴 Priorità Alta — Intervento Immediato

**[Issue Title]**
[1-3 sentences: specific ASIN, what was found, business impact.]

### 🟡 Priorità Media — Da Risolvere Questa Settimana

**[Issue Title]**
[1-2 sentences: specific details.]

### ⚪ Da Monitorare

**[Issue Title]**
[1 sentence: what to watch.]
```

**If no issues**: Write "✅ Nessun problema rilevato. Il brand è in piena salute." and skip sub-sections.

**Issue writing guidelines:**
- Always mention the specific ASIN code
- Include the exact price, seller name, rating — concrete data
- State the business impact (lost sales, brand damage, etc.)
- Don't duplicate info that's already clear from the product table

---

### 5. Cosa Fare (Action Items)

The seller's to-do list. Numbered, specific, actionable.

```
## Cosa Fare

1. **[Responsible party]** — [Exact action, on which ASIN/URL, why, optional deadline]
2. **[Responsible party]** — [...]
```

**Responsible parties** (adapt to brand context):
- **Brand manager** — for Buy Box, pricing, seller issues
- **Content team** — for A+ content, images, title updates
- **Customer service** — for review responses
- **Legal/brand protection** — for counterfeit or unauthorized seller issues

**Examples of good action items:**
> 1. **Brand manager** — Aprire un caso con Amazon Seller Support (Caso tipo: "Unauthorized seller on Buy Box") per ASIN B0XXXX. Il venditore "FastShop EU" detiene la Buy Box a €21,90 vs. prezzo brand €24,90.
> 2. **Content team** — Aggiungere A+ Content su ASIN B0YYYY (attualmente assente). Priorità: questo è il secondo prodotto per volumi di vendita.
> 3. **Customer service** — Rispondere alla recensione 1★ del 15/02/2026 su ASIN B0ZZZZ: il cliente segnala un difetto di packaging. Risposta pubblica consigliata.

**Examples of bad action items** (too vague):
> ~~1. Controllare la Buy Box~~
> ~~2. Migliorare le recensioni~~

---

### 6. Note sulle Recensioni (Review Notes)

```
## Note sulle Recensioni

[Paragraph covering review health. Include:]
```

**What to cover:**
- Overall rating health across all ASINs
- Any review worthy of a public response (mention: date, stars, key concern)
- Any positive trends to note (e.g., "Molte recensioni positive menzionano la qualità del packaging")
- If a negative review spike is detected, note it clearly

**If review situation is clean**: "Le recensioni sono stabili e positive. Rating medio: X.X/5 su N recensioni totali. Nessuna segnalazione urgente."

---

### 7. Dettaglio ASIN con Problemi (Per-ASIN Detail)

Only for ASINs with status 🟡 or 🔴. Skip entirely if all are 🟢.

```
## Dettaglio ASIN con Problemi

### [ASIN CODE] — [Short Product Name]
**Stato**: 🟡/🔴
**Marketplace**: IT
**URL**: https://www.amazon.it/dp/[ASIN]

[Paragraph: what was found (data-backed), why it's a problem, specific recommended action.]
```


## Formatting Rules for Word Document Conversion

When converting to .docx:
- H1 (`#`) → Title style
- H2 (`##`) → Heading 1
- H3 (`###`) → Heading 2
- Bold (`**text**`) → Bold
- Tables → Word tables with header row formatting
- Emoji in headings should be preserved (they render in modern Word)
- Status emojis (🟢/🟡/🔴) should be large and visible

## Tone and Language Guide

| Avoid | Use instead |
|-------|-------------|
| "Potrebbe essere un problema" | "Si tratta di un problema che richiede attenzione" |
| "Sembra che la Buy Box..." | "La Buy Box è detenuta da [seller]" (stato di fatto) |
| "È possibile che..." | Use specific data or omit |
| "Catastrophe", "grave errore" | "Richiede intervento urgente" |
| Generic: "Migliorare le immagini" | Specific: "Aggiungere almeno 3 immagini ad ASIN B0XXXX (attualmente ne ha solo 1)" |

**Numbers**: Italian format — use comma for decimals (€24,90 not €24.90), period for thousands (1.247 not 1,247)
**Dates**: Italian format — GG/MM/AAAA (28/02/2026)
**ASIN codes**: Always in code format or bold — never lowercase
